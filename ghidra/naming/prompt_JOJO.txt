Capcom CPS3 arcade game JoJo's Bizarre Adventure: Heritage for the Future (jojoba, 1999; SH-2 big-endian, Hitachi SHC compiler). Research only. 2D fighting game: 22 characters each with a Stand (summoned spirit fighting beside the user), Stand on/off mode toggle (stand button), Stand gauge (stand health; Stand Crash when broken), super meter (levels), guard / guard crush, throws + throw escape, dash, jump, combos + hit counter, Tandem attacks, Stand rush, timer, rounds, story/arcade mode, VS + character select, attract demo, HUD (health bars, stand gauge, meter), sound commands, EEPROM settings/test menu. Program at 0x06000000 (vector table: reset PC 0x06001668). Character move scripts are bytecode: FRAME records (byte0 & 0x80, length = b & 0x2F; byte1 = hold bit7 + ticks; u16 cell; attr a/b; u16 box set; s16 hit-row index -> 16-byte hit row) plus commands JUMP/JNZ/JZ/SET/ADD/CMP/AND/CALL/RET/JTABLE (from the PS1 port, likely same engine).
CPS3 memory map (approx, from MAME): 0x00000000 BIOS ROM; 0x02000000-0x0207ffff main work RAM (player objects 0x420 bytes each: P1 0x02034800, P2 0x02034c20, P1 stand 0x02035040, P2 stand 0x02035460; obj+0x1cd health/stand gauge byte; HUD mirrors 0x0205bb28 hp, 0x0205bb38 combo count, 0x0205bb48 stand hp, 0x0205bb64 meter; 0x020713a8 credits; 0x020314b4 round clock); 0x04000000 sprite RAM / sprite lists; 0x0407e000 text/char layer RAM; 0x04080000 palette RAM; 0x040c0000 video/tilemap regs, 0x040c0084.. palette DMA and character DMA (gfx decompress from flash to char RAM); 0x040e0000 sound chip regs (16 channels); 0x05000000 inputs (P1/P2 joysticks+buttons), 0x05000004 extra inputs/coins; 0x05040000 EEPROM; 0x05140000 CD/SCSI; 0x06000000-0x06ffffff flash (program + data, 0x06800000+ character data tables); 0xc0000000 SH-2 cache RAM; 0xfffffe00.. SH-2 on-chip (FRT, DIVU 0xffffff00, DMAC 0xffffff80, cache 0xfffffe92, interrupt 0xfffffee0).

Focus areas: main loop/mode dispatch, interrupts/vblank, input read + command (motion) parser, player object update, Stand control (summon/dismiss, follow position, stand gauge), move script interpreter (frame records), hitbox/collision + damage, guard/stun/throw, super meter, combo counter, projectiles, camera/scroll, sprite list build, palette, text/HUD, menus, sound, EEPROM, decompression, C runtime (memcpy/memset/sprintf plain names).
